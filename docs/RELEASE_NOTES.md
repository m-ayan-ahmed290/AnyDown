AnyDown 2.1.0 improves account setup and recovery of old downloads.

- Stops clearing WebView cookies during page loading and between account screens. Adds a Chrome client, loading indicator, reload and browser fallback. Google OAuth is intercepted with a clear explanation because Google can block embedded browsers. Use a site's own credentials or import an exported Netscape cookies.txt file; opening a browser does not automatically transfer cookies to AnyDown.
- Embedded login only accepts known session-cookie names for major social sites instead of treating anonymous cookies as a successful sign-in. Imported cookies are filtered to the chosen site's domains and expired entries are dropped. Account status says Cookies saved rather than promising a verified login. Actual account access still depends on the site.
- Adult accounts appear at the very end of Settings only when Show adult sites is enabled, with sign-in and cookie import. Adds Eporner, SpankBang, YouPorn, RedTube, Tube8 and Beeg to the directory. Availability follows yt-dlp; not every site offers accounts.
- Settings → Storage upgrade → Import old downloads lets Android grant access to files from a previous installation. Select multiple files, optionally choose a website folder, and import them into AnyDowns and the Library. Progress and success/skipped/failure counts are shown. Originals are kept; selecting an already imported source skips duplicates while the imported copy exists. If old history is unavailable, automatic site detection falls back to Other.
- A simpler home page prioritizes the link field and hides the large website directory behind Browse supported websites. Account actions expand on demand.

Signed with the same release key as v2.0.0; install over it without uninstalling. Live account sign-in has not been verified with personal credentials in this environment. Some platforms reject WebViews regardless of app configuration; cookie import remains the alternative. Back up old files before deleting originals.
